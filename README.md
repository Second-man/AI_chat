# EchoMate

EchoMate 是一个本地优先的 Windows 对话辅助工具。用户可以主动粘贴、导入聊天记录，或在明确授权后使用本地 OCR 读取当前前台微信聊天画面，再结合本地知识库生成可编辑的沟通建议。

项目遵循“用户确认后才发送”的原则：不会读取微信或 QQ 私有数据库，不会代替用户发送消息。API Key、联系人、消息、导入资料和分析结果默认保存在本机。

这是开发中的个人项目，可用于源码展示和本地试用，不是已完成安全审计的生产产品。当前主要支持 Windows 11；Android 尚未完成可用版本。项目与微信、QQ 或腾讯无官方关联。

## 当前功能

- 联系人档案、聊天消息和模型建议的本地保存。
- OpenAI 兼容 API 配置，支持自定义 Base URL 和聊天模型。
- TXT、Markdown、PDF、DOCX 资料导入、文本分块、向量化和本地 RAG 检索。
- 微信/QQ 导出文本导入，并识别“我”和“对方”的消息角色。
- Windows 悬浮助手：可拖动、缩放、收起为常驻桌面悬浮球。
- 悬浮助手中可查看全部本地聊天消息，并逐条选择发送给模型的上下文。
- Windows 微信前台监听（实验性）：仅在用户授权后通过本地窗口 OCR 和 UI Automation 识别当前聊天中新出现的文本。需要简体中文 OCR 组件，窗口布局兼容性仍需验证；手动粘贴或导入始终可用。

## 隐私与权限边界

- 微信监听只处理用户授权的前台聊天窗口（使用悬浮助手时可继续处理此前的微信窗口），不搜索其他隐藏窗口，不读取微信数据库或聊天文件。
- 切换到其他应用时监听会暂停；悬浮助手处于前台时会继续处理已经确认的微信窗口。
- 当前微信窗口内容首次只建立基线，不会自动导入旧消息。
- 新聊天窗口需要用户确认关联到本地联系人后，新增文本才会保存。
- 微信监听在明确授权后使用本地窗口 OCR 定位聊天标题和消息，截图只在内存中处理，不落盘、不上传。需要 Windows 简体中文 OCR 组件；未定位消息区域时不保存。悬浮助手覆盖区域会在 OCR 前遮罩，建议将助手移到不遮挡微信消息的位置。未验证的全树 UI Automation 文本不再作为聊天消息兜底。
- API Key 优先保存到 Windows 凭据管理器，受限环境下使用本机加密保险库，不写入 SQLite。
- `.echomate/`、本地数据库、密钥文件、构建目录和依赖目录均已加入 Git 忽略规则。
- 点击模型分析时，当前消息、所选历史消息、双方档案、分析目标和检索到的资料摘录会发送到用户配置的模型 API。本地部署并不意味着模型请求完全离线，请确认服务商的数据处理政策及聊天参与者的授权。
- 人格、情绪和沟通倾向仅是基于文本的不确定推测，不代表真实心理状态，也不构成心理诊断。
- 本地聊天数据库未加密；API Key 的保险库兜底也不等同于系统凭据管理器的安全保护。请勿在共享电脑上存放敏感聊天或高权限密钥，详见 [安全说明](SECURITY.md)。

## Windows 安装与操作教程

### 安装

在 GitHub Releases 下载最新的 Windows 安装程序（通常为 `.msi` 或 `.exe`），按向导完成安装。首次启动时，Windows 可能询问防火墙或应用权限，请只在你确认来源可信时允许。程序运行不需要单独安装 Python、Node.js 或 Rust；安装包会携带本地 API 服务。

如果 Windows SmartScreen 提示“未知发布者”，请先核对下载来源和文件哈希，再选择是否继续。当前版本是个人开发项目，尚未完成代码签名和安全审计。

### 首次配置

1. 打开 EchoMate，点击左侧的设置按钮。
2. 填写模型服务商提供的 OpenAI 兼容 `Base URL`、聊天模型名称和 API Key。
3. 可选填写自己的称呼、沟通偏好，以及 RAG 最低相似度（默认 `0.50`）。
4. 点击“保存本地设置”。API Key 优先保存到 Windows 凭据管理器，不写入 SQLite。
5. 创建联系人，填写关系、沟通特点和背景信息；这些内容只在你确认分析时作为上下文发送给模型。

### 日常操作

1. 选择联系人，粘贴当前消息，选择“对方说的”或“我发出的”。
2. 在聊天记录中勾选本次要提供给模型的历史消息；默认新识别消息会被选中。
3. 如需联网解释新梗或时事，在设置中单独保存 Tavily Key，然后在本次分析勾选“本次联网检索”，手动填写关键词，并检查发送预览。
4. 点击“查看发送预览”，确认发送内容后再请求模型建议。模型只返回建议，不会替你发送消息。
5. 可在右侧查看沟通线索、回复草案、RAG 参考片段及联网来源；悬浮助手中也可查看和收起历史建议。

### 导入资料与 RAG

在资料导入入口选择 TXT、Markdown、PDF 或 DOCX。系统会在本机提取文字、分块、向量化并保存到本地知识库。扫描版 PDF 目前需要先进行 OCR；重新导入同一原文件可按最新分块规则更新索引。

### 悬浮助手与微信监听

- 点击“悬浮助手”打开常驻窗口；拖动顶部区域移动，点击“收起”变为桌面悬浮球，点击悬浮球重新展开。
- 微信监听必须由用户主动授权，并将微信置于前台。首次画面只建立基线，不导入旧消息；新窗口需要确认关联到本地联系人。
- 监听使用本地窗口截图 OCR，检测到新增消息后同步到悬浮窗；左侧归类为对方，右侧归类为我。请避免悬浮窗遮挡微信消息区域，并保持微信输入框与最近消息可见。
- 监听兼容性受微信版本、窗口缩放、系统 OCR 语言包和气泡布局影响。识别异常时可以停止监听，改用手动粘贴或导入聊天文本。

### 数据与隐私

联系人、消息、资料索引和分析历史默认保存在本机数据目录；模型分析会将你选择的聊天上下文发送到配置的模型 API。不要上传真实聊天、API Key 或本地数据目录到公开仓库；联网检索只接收你确认的关键词。

## 开发启动

需要 Node.js 22.12+（推荐当前 LTS）、pnpm、Python 3.11、Rust stable（满足 Cargo.toml 的 rust-version）、Visual Studio C++ Build Tools/Windows SDK，以及 WebView2 Runtime。

首次克隆后，在 CMD 中执行（目录可自行替换）：

```cmd
git clone https://github.com/Second-man/AI_chat.git
cd AI_chat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
pnpm install --frozen-lockfile
set "ECHOMATE_PYTHON=%CD%\.venv\Scripts\python.exe"
node_modules\.bin\tauri.cmd dev
```

后续启动仍需设置 `ECHOMATE_PYTHON`，并确保 pnpm 和 Cargo 位于 PATH 中。后端由 Tauri 自动启动，无需单独启动。Python 依赖目前未锁定完整版本，跨环境复现可能需要适配。

启动后应看到本地 API 服务监听：

```text
Uvicorn running on http://127.0.0.1:8787
```

## 本地 RAG 检索

参考资料按最多 280 字符、重叠 60 字符切分，优先使用段落、换行和句号边界，在本地向量化。每次用当前联系人最近 4 条已勾选消息（标明双方）、当前消息和沟通目标拼接检索文本，不额外调用模型；最多提供 3 个完整资料片段。模型仍收到本次全部已勾选聊天上下文，检索不读取未勾选消息或其他联系人的记录。

已有资料不会自动重新分块。重新导入同一原文件可更新旧索引；新向量构建成功后替换旧索引，构建失败保留旧资料。最新分块版本的相同文件再次导入会提示资料已存在。历史分析保留当时的参考片段，不随索引更新改变。

设置页可配置 RAG 最低余弦相似度（-1～1），默认 0.50 是待校准的试用值，不是正确概率。检索最多 12 个候选，过滤后最多发送 3 个完整片段；没有合格资料时不强行补足。桌面和悬浮助手显示参考分数，并区分知识库为空、无合格结果和检索错误。首次使用会将旧向量分批复制到余弦索引，保留旧索引；此过程不需要重新下载或重新嵌入资料，也不改变历史分析。

## 可选联网检索

在设置中单独填写 Tavily API Key（不与模型 Key 共用，可单独清除）。桌面和悬浮助手默认不联网：每次分析自行勾选“本次联网检索”，手动填写不含个人资料的关键词，并在发送预览确认。取消不会发出搜索请求，成功或取消后联网选项重置。

搜索仅向 `https://api.tavily.com/search` 发送确认的关键词及搜索选项；最多返回 5 条摘要，超时 15 秒、不自动重试。搜索失败时可重试或明确关闭联网再分析。模型会收到搜索摘要，以及原有聊天、档案和本地 RAG 上下文。关键词也可能含有隐私信息，请自行检查；额度和费用以 Tavily 账户为准。

结果在服务内存保留 15 分钟，服务重启后失效，不导入向量库。回复中的 `[W1]` 等实际来源单独展示标题、链接、摘要和日期；历史建议保留其引用。查不到信息或资料冲突时要求模型说明不确定，但联网不保证事实或建议正确，也不能修复 OCR 原文错误。

## 本地验证命令

```cmd
.venv\Scripts\python.exe -m unittest discover -s backend\tests -v
pnpm build
cd src-tauri
cargo check
cargo test
```

这些检查不会打包安装程序，也不能证明真实微信窗口读取成功。监听兼容性需在对应微信版本上单独验证。

后端测试覆盖本地加密 Key 兜底、联系人和消息持久化、聊天记录导入、文本提取与分块、向量化失败回滚、分析上下文选择、微信映射和同步去重。

联网测试额外覆盖搜索凭据隔离、超时、错误 Key、无结果、缓存过期、来源恢复及不可信摘要。浏览器模拟验收：先启动 `pnpm dev`，安装 Playwright 并提供 Edge，执行 `node scripts/test-web-search.cjs`（可通过 `ECHOMATE_PLAYWRIGHT` 指定已有 Playwright 模块）。模拟测试不会调用真实搜索或模型；真实检索及回答质量仍须配置 Key 后验收。
